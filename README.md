# kante-forecasts

Kante が、結果が出る前に出した予想を残す場所です。予想は出した時点でコミットし、あとから書き換えません。書き換えていないことは、このリポジトリのコミット履歴で確かめられます。

## 雪道の通行止め(2026〜2027年の冬)

高速道路と国道の管理者が出す「予防的通行止め」について、次の3つを当てます。
- その雪で、雪国のどこかが止まるか(北陸地方整備局が「大雪のおそれ」を出した時点で予想する。式 雪国 v0)
- 止まるか、何時に止まるか(管理者の通行止めの予告が出た時点で予想する。式 v0)
- いつ開くか(止まった時刻が分かった時点で、開く前に予想する。式 解除 v0)

### 式
| 式 | ファイル | 固定した日時(日本時間) | sha256 |
|---|---|---|---|
| v0(止まるか・何時に止まるか) | `yobouteki/formula/v0.md` | 2026年11月14日 15:26 | `9bfd02c9abd5fce40a5ee36afe654438492ce7131cd2e52730ac9ffa8f4a1e37` |
| 解除 v0(いつ開くか) | `yobouteki/formula/kaijo-v0.md` | 2026年11月15日 | `bef81b8118a0d1abd836393cea11816f0f68ea99f4af4004d332a4bb752da979` |
| 雪国 v0(その雪で雪国が止まるか) | `yobouteki/formula/yukiguni-v0.md` | 2026年11月15日 | `317184527d66caccea9f2d5018d5d4f2cb584d324c8f1cfed656565f02922723` |

- `sha256sum -c yobouteki/formula/SHA256SUMS`(yobouteki/formula の中で実行)で一致を確かめられます
- 式を変えるときは v1 として別のファイルにします。v0 は消しません

### 対象
雪の多い区間だけで答え合わせします。
- 北陸道(米原〜新潟)、関越道(水上〜長岡)、上信越道(信濃町〜上越)、舞鶴若狭道(敦賀〜若狭美浜)、名神高速の関ケ原付近
- 上の区間の並行国道(国道8号、17号、18号、27号、21号)
- 式 v0 の本文は中部・近畿・関東も対象にしていますが、この冬の答え合わせは上の区間だけで行います
- 解除 v0 の対象は、式の本文の「対象」に書いた区間と種類だけです

### 「当たり」の決め方(式 v0)
- 止まるか: 予想(止める/止めない)と、実際に止まったかが同じなら当たり
- 開始時刻:
  - 予告が「予定」のとき: 予告の時刻ちょうどに止まったら「合う」
  - 予告が「可能性」のとき: 予告の幅の中、遅くとも幅の終わりから2時間以内に止まったら「合う」
- 止まらなかったとみなす時: 予告の幅の終わり(幅がなければ予告の時刻)から24時間たっても、その区間で通行止めの実施が発表されなかったとき
- 成績は1つの数字にまとめず、次の2つで出します
  - 「止める」と言った回のうち、本当に止まった数
  - 実際に止まった回のうち、事前に当てていた数

### 「当たり」の決め方(雪国 v0)
- 発表ごとに、予想(止まる/止まらない)と、式の本文の「止まったとみなす通行止め」があったかが同じなら当たり
- 数える期間は、最初の発表の日から、発表に書かれた予想の期間の終わりの翌日まで

### 「当たり」の決め方(解除 v0)
- 式の本文の「合う」の決め方のとおり(規則ごとに、止めてから何時間の間に開いたら「合う」かを決めてある)

### ファイル
- `yobouteki/2026-27/predictions.csv` / `results.csv`: 式 v0 の予想と結果
- `yobouteki/2026-27/kaijo_predictions.csv` / `kaijo_results.csv`: 解除 v0 の予想と結果
- `yobouteki/2026-27/yukiguni_predictions.csv` / `yukiguni_results.csv`: 雪国 v0 の予想と結果
- 予想は結果が出る前に1行ずつ足します。足した行は書き換えません。結果は予想IDごとに、結果が出たあとで足します

管理者の発表文は転載していません。載せているのは、予告の区分・区間・時刻と、Kante の予想と結果だけです。
