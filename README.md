# kante-forecasts

Kante が、結果が出る前に出した予想を残す場所です。予想は出した時点でコミットし、あとから書き換えません。書き換えていないことは、このリポジトリのコミット履歴で確かめられます。

## 雪道の通行止め(2026〜2027年の冬)

高速道路と国道の管理者が出す「予防的通行止め」の予告から、本当に止まるか、何時に止まるかを当てます。いつ開くか(解除)は当てていません。

### 式
- 使う式は `yobouteki/formula/v0.md`(式 v0)。2026年11月14日 15:26(日本時間)に固定しました
- 式の本文の sha256 は `9bfd02c9abd5fce40a5ee36afe654438492ce7131cd2e52730ac9ffa8f4a1e37` です(`yobouteki/formula/SHA256SUMS`)。`sha256sum yobouteki/formula/v0.md` で一致を確かめられます
- 式を変えるときは v1 として別のファイルにします。v0 は消しません

### 対象
式 v0 のうち、雪の多い区間だけで答え合わせします。
- 北陸道(米原〜新潟)、関越道(水上〜長岡)、上信越道(信濃町〜上越)、舞鶴若狭道(敦賀〜若狭美浜)、名神高速の関ケ原付近
- 上の区間の並行国道(国道8号、17号、18号、27号、21号)

### 「当たり」の決め方
- 止まるか: 予想(止める/止めない)と、実際に止まったかが同じなら当たり
- 開始時刻:
  - 予告が「予定」のとき: 予告の時刻ちょうどに止まったら「合う」
  - 予告が「可能性」のとき: 予告の幅の中、遅くとも幅の終わりから2時間以内に止まったら「合う」
- 成績は1つの数字にまとめず、次の2つで出します
  - 「止める」と言った回のうち、本当に止まった数
  - 実際に止まった回のうち、事前に当てていた数

### ファイル
- `yobouteki/2026-27/predictions.csv`: 予想。予告が出たら、止まる前に1行ずつ足します。足した行は書き換えません
- `yobouteki/2026-27/results.csv`: 結果。予想IDごとに、結果が出たあとで足します

管理者の発表文は転載していません。載せているのは、予告の区分・区間・時刻と、Kante の予想と結果だけです。
